# Les sources publiques

Fichier de contexte pour le projet Claude « Ma formation ». Il liste où vérifier un fait. Claude : cite la source, l’année et le lien ; écris « à vérifier » quand tu ne peux pas ouvrir la page.

## Sur Claude et sur GitHub

- Aide officielle d’Anthropic : support.claude.com. Les libellés de l’interface changent : l’aide fait foi.
- Offres et prix de Claude : claude.com/pricing. Les prix sont affichés en dollars.
- GitHub Pages : docs.github.com.

## Sur le public et le contexte

- Insee, « Dossier complet » : https://www.insee.fr/fr/statistiques/2011101 (population par âge, emploi).
- Insee, « Comparateur de territoires » : https://www.insee.fr/fr/statistiques/1405599.
- Annuaire des Entreprises : https://annuaire-entreprises.data.gouv.fr/ (une entreprise ou un organisme : activité, effectif, comptes publiés).
- data.gouv.fr : https://www.data.gouv.fr/ (données ouvertes).

## Sur la formation

- France compétences : https://www.francecompetences.fr/
- Légifrance : https://www.legifrance.gouv.fr/ (textes de loi et règlements).
- Éduscol, pour un programme de lycée : https://eduscol.education.fr/

## Règle

Ouvrir la source, noter l’année et le lien. Un fait sans source est retiré. Un chiffre se vérifie à la source.
